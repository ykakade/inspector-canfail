# README language

The README uses the writing rules and dictionary in [ASD-STE100, Issue 9](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf).

## Rules

- Use a maximum of 20 words in an instruction.
- Use a maximum of 25 words in a description.
- Give one instruction in each sentence.
- Use a maximum of six sentences in a paragraph.
- Use the active voice.
- Use simple verb forms.
- Use the same term for the same item.
- Use approved words with their approved meanings and parts of speech.

The standard permits technical nouns and technical verbs for a specified subject field. The terms below apply to software and software tests.

## Technical nouns

| Term | Meaning in this project |
|---|---|
| AI coding agent | Software that uses an AI model to change code. |
| assertion | An expression that compares a result with a requirement. |
| behavior | The results and effects that a requirement specifies for software. |
| boundary | A value where a condition changes its result. |
| checker | The canfail command-line software. |
| hook | A command that the agent host starts after a specified action. |
| mock | A replacement for a software dependency during a test. |
| mutation | A source change that canfail applies during a check. |
| runtime dependency | Other software that the checker must load to operate. |
| scan | An examination of test patterns without a test run. |
| score | The percentage of mutations that cause a command failure or timeout. |
| skill | Instructions that an AI coding agent can load. |
| test run | One operation of the test command. |
| test suite | A group of software tests. |
| timeout | The time limit for a command, or the result when that limit expires. |

Product names, command names, file paths, and code identifiers keep their specified forms. The checkout example also uses its application terms, such as shipping cost and receipt.

## Technical verbs

| Verb | Meaning in this project |
|---|---|
| call | Start a function with specified arguments. |
| edit | Change the contents of a file. |
| enter | Supply text to a command interface. |
| fail | Give a test or command result that signals an error. |
| pass | Give a test or command result that signals success. |
| restore | Replace changed source text with the saved source text. |
| run | Start a software command and let it operate. |
| save | Write data to a file for subsequent retrieval. |
| skip | Exclude a test from a test run. |

These verb meanings apply only to software operations. General text uses the approved dictionary alternatives.
